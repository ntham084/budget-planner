# Budget Planner

A personal finance web app built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Current state

Every section is interactive: add/edit/delete accounts, transactions, budget categories, bills, and goals; allocate paychecks; view a computed net worth breakdown. Data is seeded with realistic examples and persisted to the browser's localStorage — no database, auth, or APIs yet.

Sections: Dashboard, Accounts, Transactions, Budget, Bills, Paycheck, Goals, Net Worth.

## Getting started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
